## A. Pre-Train EDA

| ID | Figure File | Layout | Plot Type | What It Shows | Key Finding |
|----|-------------|--------|-----------|---------------|-------------|

| A4 | `fig_pre4_video_sample_counts.png` | Standalone | Stacked bar (per video) | Window count per video clip coloured by class | MOT17 clips dominate normal windows; all threat windows concentrated in short custom clips |

## B. Post-Train Behavioural EDA

| ID | Figure File | Layout | Plot Type | What It Shows | Key Finding |
|----|-------------|--------|-----------|---------------|-------------|
| B1 | `fig_post1_confidence_dist_3models.png` | 1×3 | Overlaid histograms | Softmax confidence score per class for each model | BiLSTM: bimodal (peaks at 0.42 and ≥0.97) — poorly calibrated; STGAT: spread 0.3–1.0; XGBoost: normal peak near 1.0, threat classes spread |
| B2 | `fig_post2_per_video_acc_3models.png` | 1×3 | Horizontal bar (per video) | Per-video accuracy with 70% threshold line | XGBoost: 5 videos ≥70%; STGAT: 2; BiLSTM: 1; all models fail on `[Following] Movie(3)_003` and `[Surrounding] Movie(4)_010` |
| B3 | `fig_post3_timeline_stgat_xgb.png` | 1×2 | Dot plot (window index vs class) | Predicted vs ground-truth class over time for 4 sample videos | Both models track normal correctly; fail to separate `following` from `surrounding`; XGBoost makes fewer spurious predictions on normal clips |
| B4 | `fig_post4_xgb_error_analysis.png` | Standalone | Overlaid histograms (2×5) | Feature value distributions: correct vs incorrect XGBoost predictions | Errors concentrate at `threat_person_count=1`; ambiguous zone at `min_distance` 50–150 px; low `max_velocity_toward_target` causes fast\_approach misclassification |

## C. XAI / SHAP Interpretability

| ID | Figure File | Layout | Plot Type | What It Shows | Key Finding |
|----|-------------|--------|-----------|---------------|-------------|
| C1 | `fig_xai1_shap_waterfalls_4class.png` | 2×2 | SHAP waterfall bars | Per-feature SHAP attribution for one representative sample per class | `normal` ← `group_speed_std`; `following` ← `threat_person_count` + `avg_distance_consistency`; `surrounding` ← `avg_distance_consistency`; `fast_approach` ← `target_speed` (and `threat_person_count` strongly negative) |

| C3 | `fig_xai3_bilstm_attention.png` | 1×2 | Heatmap + Line curve | (a) BiLSTM attention weights per sample per frame; (b) mean temporal attention — **normal class only** | Bell-curve attention pattern; peaks at frames 14–18 of the 30-frame window; first/last 5 frames largely ignored |
| C4 | `fig_xai4_stgat_attention.png` | 1×2 | Line plot + Bar chart | (a) STGAT attention from target to nearby persons over time; (b) mean attention per graph node — **normal class only** | Attention decays sharply with graph distance (person 1 ≈26%, person 5+ ≈0%); weights are stable over time — model lacks dynamic re-weighting |

> Separate from EDA. Place in the **Results** section under *Quantitative Evaluation*.

|----|-------------|--------|-----------|---------------|-------------|
